## 三、关于「安卓软件」的重要说明

- 仓库中的 `SoloTalk.py` 是 **Windows 电脑版**（PyQt5 + Vosk + fastembed/BGE + VLC），不是安卓代码。
- 安卓版（`version.json` 里 `mobile.version = 2.2`，更新说明「新增题库页」）只提供编译后的 APK，未开源源码。
- 从 APK 解析出的技术栈：Kotlin（9 个 dex）、ONNX Runtime（4 个 ABI 的 `libonnxruntime.so`）、Vosk（4 个 ABI 的 `libvosk.so`）、BGE ONNX 模型、Vosk 声学/解码模型 —— 与电脑版是**同一套评分思路**（BGE 语义相似度 + Vosk 识别）。因此本次评分引擎的优化对两个平台同样适用。
- 我**没有**反编译或重签名原 APK：在无源码、无签名私钥、且不知道原工程结构的前提下，直接改 smali 既不可靠也无法验证，交付一个「看起来改过但装不上」的 APK 没有意义。取而代之的是提供可直接集成的 Kotlin 内核与精确的体积诊断。

## 六、还没做 / 需要你决定的事

1. **没有重编译 APK**：若你手上有安卓源码工程，把 `android/` 的 `.kt` 放进去，按 `android/README.md` 调整 Gradle 即可产出真正瘦身的 APK。评分内核 `GdCelstScoring.kt` **已用 Kotlin 2.0.21 JVM 编译器编译通过**，并与 Python 版做过 6 组输入逐字段一致性验证；`SoloTalkScoringBridge.kt` 因依赖 Android SDK 未在本沙箱编译，需由你的 Gradle 工程编译。若需要更深的分析或协助搭建工程，请提供源码仓库。
2. **在线评测服务需自备**：`SOLOTALK_ASR_ENDPOINT` / 在线 ASR 端点由你配置（可指向自建服务或合规云 ASR）。未配置时引擎走离线保守评分，仍能出分，但「发音/语音语调」维度只是近似（引擎已标注来源并封顶）。
3. **令牌安全**：你提供的 GitHub PAT 以明文出现在对话中，请**立即撤销并重新生成**。本次仅用于只读 API 访问，未做任何写入操作。
4. **官方真题**：如需真正历年真题，需从 QQ 群「共创题目」文件夹或合规渠道获取后放入 `assets/question_bank/`；本次未擅自抓取任何受版权保护的题库。
