## 二、听说功能（新增）

原软件只提供「录音 → 出分」，缺少完整的听说训练闭环。新增能力：

| 功能 | 说明 | 实现 |
|---|---|---|
| **听 · 示范朗读** | Part A 原文、Part B 听力材料、Part C 故事可语音播放，语速 0.6–1.3× 可调 | 浏览器内置 `speechSynthesis`（en-GB 优先），无需后端、无需下载音频 |
| **听 · 真实听力音频** | 用户上传的江门八下听说综合原题含 3 段 mp3，已内置并可直接播放 | 后端 `/api/audio/<id>/<n>` 从 `.solo` 内**按需流式读取单个条目**，不解压整包 |
| **说 · 语音识别** | 跟读、三问、五答、复述均可直接说出，自动转写为文本 | 浏览器 Web Speech API（Chrome / Edge，需麦克风权限） |
| **说 · 文本兜底** | 浏览器不支持识别或麦克风不可用时，可直接输入文本，**评分照常可用** | 输入框 + 同一评分接口，保证弱网/无设备也能练 |
| **计时** | 跟读与复述带计时器，可模拟考场节奏 | 前端计时，作答时长一并提交用于语速维度 |
| **分步练习** | Part A / B / C 三段式面板，可来回切换、查看参考答案与要点提示 | 单页应用，无需刷新 |
| **逐维度评分** | 语音语调、语速与内容、语言、信息、内容要点、流利程度逐项出分 + 档次 + 卷面 60 分 + 折算 20 分 | 复用已验证的 `scoring/gd_celst.py`，与电脑版/安卓版同一套引擎 |
| **改进建议** | 按各维度短板生成针对性建议（漏读、语速、疑问词语序、要点覆盖等） | 后端 `_advice()` |
| **练习记录** | 本机保存成绩与趋势图，可导出 JSON、清空 | `localStorage`，不上传任何数据 |
| **出处核查** | 每套题可查看来源链接、年份、卷别、完整度与免责声明 | `meta.source` + 出处弹窗 |
| **题库筛选** | 按学段、来源类型（真题/回忆/模拟/上传/原创）筛选与搜索 | 前端过滤 |

### 关于评分精度的诚实说明

浏览器语音识别**只提供文本**，没有音素级置信度、停顿、语速等韵律信号。因此：

- 发音 / 语法维度走评分引擎的**离线近似**路径（用词级对齐作可解释代理），并在报告里明确标注
  「离线近似评分（发音维度为代理值）」；
- 语音语调分已按官方 B 档**封顶**，不会把「念得好听」错误地当成高分；
- 若在 `SOLOTALK_ASR_ENDPOINT` 配置了在线音素级评测端点，同一套引擎自动切换为在线精细评分，
  **无需修改任何评分逻辑**。

### 双格式兼容（重要）

用户上传的 `.solo` 是**初中听说综合**格式：
`partA` / `partB_secA`（听选信息）/ `partB_secB`（回答问题）/ `partC_secA`（复述）/ `partC_secB`（提问）。

而电脑版源码读取的是**高考 CELST** 格式：
`partA.hidden_text` / `partB.three_questions` + `five_answers` / `partC.tts_text` + `key_points`。

**本轮生成的每一套 `.solo` 都同时写入两套字段**（同一份 `data.json` 中键名不冲突，直接合并），
因此：

- 电脑版 `SoloPackage.from_dict()` 能直接打开；
- 手机版听说综合界面能直接打开；
- 评分引擎 `grade_exam()` 能直接批改；
- 新的 Web 应用能直接练习。

题型映射依据：CELST「三问」≡ 听说综合「提问」；「五答」≡「回答问题」；
「故事复述」≡「短文复述」；「模仿朗读」≡「模仿朗读」。二者为同源题型。

### 体积控制

- 除用户上传原题外，17 套**全部为纯文本**，由 App / 浏览器 TTS 合成音频，单套 2.8–4.4 KB；
- 用户上传原题含 3 段 mp3 共约 459 KB（保留了真实听力，值得保留）；
- **题库合计约 518 KB**，ZIP 最高压缩级别，按需加载（列表只读索引，选中才打开对应包）。

## 三之二、优化版安卓 APK（本轮新增，直连下载）

除 Web 应用外，本轮额外交付了**真正的安卓 APK**：`SoloTalk-Optimized-v1.0.apk`（包名 `com.solotalk.optimized`，version 1.0，自签名）。

- **安装**：手机「设置 → 安全 → 允许未知来源应用」后直接装 APK；
- **内置**：18 套带出处题库 + CELST 评分引擎（移植为纯 JS，WebView 离线运行）+ 听说练习全流程；
- **识别依赖**：语音打分走系统 `SpeechRecognizer`（多数机型为联网识别）；无网络 / 不可用时会自动提示「手动输入」英文作答，评分照常；
- **TTS 朗读**走系统 `TextToSpeech`，可离线。

### 内存 / 体积问题的根因与解决（235 MB → 568 KB，缩减约 99.8%）

原版手机 APK 高达 235 MB 的根因是**内置了庞大的 TTS 引擎与识别 / 大模型**。优化版的做法：

| 项目 | 原版 | 优化版 APK |
|---|---|---|
| TTS 引擎 | 内置（巨大） | **调用系统 TextToSpeech**，零内置 |
| 语音识别 | 内置模型 | **调用系统 SpeechRecognizer**，零内置 |
| 评分内核 | Python 运行时 | **移植为纯 JS**，WebView 内离线运行 |
| 题库音频 | 全量打包 | 仅 552 KB（含江门题 3 段 mp3），其余用系统朗读 |
| 原生库 | 多 `.so` | **纯 Java WebView，无 `.so`** |

运行时 RAM 同样极小：不加载任何大模型，只有前端 + JS 引擎 + 题库。

## 四、应用结构

```
webapp/
├── app.py                 Flask 后端：题库 / 音频 / 评分 / 下载 API
├── requirements.txt       flask
└── static/
    ├── index.html         单页应用（题库/练习/记录/下载/关于 5 个视图）
    ├── style.css          响应式样式（手机可用）
    └── app.js             TTS、语音识别、计时、评分报告、记录、出处弹窗
```

主要接口：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/bank` | 题库索引（含出处元数据） |
| GET | `/api/paper/<id>` | 单套题内容（双格式字段 + 出处） |
| GET | `/api/audio/<id>/<n>` | 按需读取内置听力音频 |
| POST | `/api/score` | 提交作答 → CELST 逐维度报告 + 建议 |
| GET | `/api/scoring-info` | 评分标准说明 |
| GET | `/download/<name>` | 实时打包下载（question_bank / full / scoring / android / desktop / docs） |
| GET | `/download/one/<id>` | 下载单套 `.solo` |
| GET | `/health` | 健康检查 |

本地运行：

```bash
cd SoloTalk-Optimized
pip3 install -r webapp/requirements.txt
PORT=3000 python3 webapp/app.py
# 浏览器打开 http://127.0.0.1:3000/
```
