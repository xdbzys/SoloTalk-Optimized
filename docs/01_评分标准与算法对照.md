# 广东高考英语听说（CELST）评分标准与算法对照

> 优化依据来自公开资料：百度百科《广东高考英语听说考试》「评分标准（2011年3月版）」全文、
> 2025 年广东高考听说备考资料对机考评分维度的说明、以及分数折算规则。
> 本文件是 `scoring/gd_celst.py` 与 `android/GdCelstScoring.kt` 的设计说明。

## 一、考试结构与折算规则

全卷 3 道大题，卷面满分 **60 分**，考试约 30 分钟；2021 年起按 **卷面 ÷ 3、四舍五入取整** 折算为 **20 分**计入高考英语总分。

| 题序 | 题型 | 题量 | 卷面赋分 |
|---|---|---|---|
| Part A | Reading Aloud 模仿朗读 | 1 | 20 |
| Part B | Role Play 角色扮演 | 1（三问 + 五答，共 8 小题） | 16 |
| Part C | Retelling 故事复述 | 1 | 24 |
| 合计 | | 3 | **60** |

> 折算细节：官方为「四舍五入」。`round_half_up(x) = floor(x + 0.5)`，
> **不能用 Python 内建 `round()`**（银行家舍入会让 1.5→2 侥幸正确、但 2.5→2 出错）。

## 二、官方评分档次表（逐条摘录）

### Part A 模仿朗读（语音语调 12 + 语速与内容 8）

| 档次 | 语音语调 | 标准 | 语速与内容 | 标准 |
|---|---|---|---|---|
| A | 8–12 | 发音清晰、准确，语调正确、自然，语流连贯、流畅 | 6–8 | 按照原语速朗读，而且内容完整（至多漏过三个单词） |
| B | 4–7 | 发音基本标准，语调基本正确，语流尚为连贯 | 3–5 | 基本按照原语速朗读，漏过几个单词 |
| C | 0–3 | 大部分音素发音不正确，语调不正确，语流不连贯 | 0–2 | 不能按照原语速朗读，漏过一个完整的句子或者超过 10 个以上单词 |

机考实际把 Part A 归纳为 **准确度 / 流畅度 / 完整度** 三个维度。

### Part B 角色扮演（三问 3×2 分 + 五答 5×2 分 = 16 分）

| 维度 | 提问（每题） | 回答（每题） |
|---|---|---|
| 语言 | **1.5** 语法结构和选词正确<br>**1.0** 基本正确（时态/语态、动词及物性、主谓一致有误扣 0.5）<br>**0** 导致不能理解，如疑问词错误、结构不完整且意义不连贯 | **0.5** 不影响理解所表达的信息<br>**0** 出现严重语法和选词错误，导致误解或不能理解 |
| 信息 | **0.5** 基本按照要求传递了信息<br>**0** 不能按照要求传递信息 | **1.5** 按照要求传递信息<br>**1.0** 基本传递（漏一两点次要信息、或添加无关信息）<br>**0** 不能按要求传递信息 |

### Part C 故事复述（内容 12 + 语言 4 + 流利 5 + 语音 3 = 24 分）

| 档次 | 内容 | 语言 | 流利 | 语音 |
|---|---|---|---|---|
| A | 8–12 涵盖原文大多数信息点 | 3–4 语言规范 | 4–5 流利 | 3 语音语调不影响理解 |
| B | 4–7 涵盖原文主要信息点 | 2 语言基本合乎规范 | 2–3 比较流利 | 2 有些错误但基本不影响理解 |
| C | 0–3 涵盖原文部分信息点 | 0–1 出现较多语言错误 | 0–1 不够流利 | 1 影响理解 |

## 三、原 SoloTalk 评分逻辑的三处系统性缺陷

原实现位于 `SoloTalk.py` L840–937、L988–1111、L6085–6122：

| # | 原实现 | 问题 | 后果 |
|---|---|---|---|
| 1 | Part A：`score = (1 − WER) × 20`，`wer = edit/ref_len` **未钳制** | 单维度只测「文本吻合」，完全不评语音语调/语速；识别文本比原文长时 `wer > 1` → **负分** | README 自述「A 偏低」；极端情况出现负分 |
| 2 | Part B：`score = sim × 2`，`sim = BGE(cos+1)/2` 或 Jaccard | **`(cos+1)/2` 把 [-1,1] 映射到 [0,1]，两句完全无关的英文也稳定得 ≈0.5** → 每题白拿 1 分；且语言/信息不分维度 | README 自述「B 偏高」；**全程未作答仍得 8 分** |
| 3 | Part C：`score = mean(max(词袋命中, BGE语义)) × 24`，再乘 `(词数/20)²` | 24 分全压在「要点覆盖」一维，官方的语言/流利/语音三维完全不计分；长度惩罚阈值「20 词」是拍脑袋，与原文长度无关 | 复述评分与官方档次表不可对齐 |
| 4 | 无折算、无档次 | 只输出卷面 60 分制，没有 60→20 折算，也没有 A/B/C 档次 | 与考生实际查到的成绩口径不一致 |

## 四、优化版引擎设计（v3.0）

### 4.1 维度拆分与档次映射

新增 `officialBand(q, A档区间, B档区间, C档上限)`：把 0~1 的质量分按官方三段式映射，并在档内线性微调。既保留档次语义，又避免「一个线性相似度乘满分」的失真。

| 部分 | 优化版实现 |
|---|---|
| Part A | 语音语调 0–12（在线音素置信度；离线用词级对齐代理）+ 语速与内容 0–8（按官方「漏 ≤3 词 / ≤10 词 / 更多」三段 + 语速微调）。`accuracy` 钳制 [0,1] |
| Part B | 三问：语言 {0, 1.0, 1.5} + 信息 {0, 0.5}；五答：语言 {0, 0.5} + 信息 {0, 1.0, 1.5}。疑问句结构单独校验（疑问词、助动词前置、语序、长度） |
| Part C | 内容 0–12（要点覆盖三段式）+ 语言 0–4 + 流利 0–5 + 语音 0–3；长度惩罚与**原文长度**挂钩（`hyp/src < 18%` 才线性衰减） |
| 折算 | `floor(卷面/3 + 0.5)`，clamp 0–20；输出 A/B/C 总档与各 Part 分档 |

### 4.2 消除「相似度虚高」的硬门槛

`text_utils._phrase_hit()` / Kotlin `phraseHit()`：

- 弃用 `(cos+1)/2`，改用**词形归一 + 同义归并 + 内容词命中**；
- 命中率 `< 0.5` 直接记 0（不足一半要点词视为未覆盖）；
- 语言维度设 `LANG_FLOOR = 0.28`，低于即记 0；
- 未作答 / 识别为空 → **整题 0 分**。

### 4.3 交叉校验：防止「念了别的却拿满发音分」

若在线发音评测返回高分，但识别文本与原文整体对不上（`alignment.accuracy < 0.35`），语音语调分随内容对齐一并压到 C 档。否则会出现「朗读完全跑题却拿满 12 分」的漏洞。

### 4.4 「结合网络」的落地点

`asr_provider.AutoASRProvider`：

```
联网 → OnlineASRProvider：识别文本 + pronunciation(音素置信度) + grammar + duration/wpm + pause_ratio
       ↓ 失败 / 超时 / 无网络
离线 → OfflineASRProvider（本地 Vosk，流式读 4000 帧，不整段载入）
```

在线信号正好补齐官方评分里离线无法提供的「语音语调 / 流利程度」；断网时引擎**自动走保守近似**（Part C 语音维度封顶 2 分、`score_report.online_used=false` 并在 UI 标注），考场弱网也能完整出分。

### 4.5 零模型依赖

新引擎纯标准库（Python）/ 纯 Kotlin 标准库实现，**不加载 BGE ONNX、不需要 ONNX Runtime**。这既消除了相似度偏差，也是「内存减小」的最大单项来源（详见 `03_内存与体积优化报告.md`）。

## 五、定量验证

见 `report/verification_report.md`（10 个典型场景）与 `report/integration_report.md`（源码集成）。关键结果摘要：

| 场景 | 原算法卷面 | 优化版卷面 | 说明 |
|---|---:|---:|---|
| 全程未作答 | **8.00** | **0.00** | 原 `(cos+1)/2` 基线白送分 |
| 语义完全无关但句子通顺 | 13.15 | 7.52 | 信息/内容维度已归零；语言/流利留存符合官方「四维独立」 |
| 识别文本远长于原文 | **−13.38** | **0.60** | 负分修复 + 跑题降级 |
| 无意义单词堆砌 | 9.08 | 2.83 | 噪声刷分被抑制 |
| 全优作答 | 53.03 | **57.06 / 60 → 19 / 20（A 档）** | 新增折算与档次 |

> **关于「无关文本」的总分**：官方 Part C 明确规定内容/语言/流利/语音四维**独立给分**，
> 因此「用通顺英语流利地讲了一段完全无关的内容」在语言、流利、语音三维仍会得分。
> 这不是缺陷；准确的度量是**信息维度与内容维度是否归零**（验证中均已归零）。
> 原算法总分低只是因为它把所有维度压成一个相似度，属于「错得恰好不明显」。

## 六、诚实说明的局限

1. **离线发音维度是弱代理**：无音素级评测时，Part A 语音语调以词级对齐准确率近似，Part C 语音保守封顶 B 档（≤2 分）。要完全对齐官方机考，需接入在线发音评测。
2. **语法维度是启发式**：`sentence_wellformedness()` 用功能词占比、重复率、长度等轻量特征，不依赖语法模型；在线 `grammar` 字段优先。
3. **同义词表是有限集**：`text_utils._SYNONYM_GROUPS` 覆盖高考听说高频改写，可按题库扩充，不需重训模型。
4. **评分不等于官方机考成绩**：本引擎用于练习自评与档次参考，最终成绩以广东省教育考试院公布为准。
