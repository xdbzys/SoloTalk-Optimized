# 集成指南

## 快速开始（零改动体验评分引擎）

```bash
cd SoloTalk-Optimized
python3 tools/verify_scoring.py        # 10 个场景准确度对照 → report/verification_report.md
python3 tools/verify_integration.py    # 优化版源码集成验证 → report/integration_report.md
python3 tools/verify_parity.py         # Python/Kotlin 双端一致性 → report/parity_report.md
python3 scoring/question_bank.py       # 题库按需加载自检
python3 tools/analyze_apk.py --tail <apk末尾片段> --total 235045570
```

评分引擎为**纯标准库**，无需 pip 安装任何包。

## 一、电脑版（PyQt5）

### 1.1 直接替换

`app/SoloTalk_optimized.py` 由原始 7626 行源码生成，**只改 4 处**（详见 `app/solotalk_patch.diff`），
其余编辑模式 / 练习模式 / 模考模式 / 历史记录 / 结果卡片完全不变。

保持目录结构即可运行（`scoring/` 与 `app/` 同级）：

```
SoloTalk-Optimized/
├── app/SoloTalk_optimized.py
└── scoring/            ← 通过 sys.path 自动加入
```

```bash
cd SoloTalk-Optimized/app
python3 SoloTalk_optimized.py
```

> 若把脚本单独拷到别处，请设置 `PYTHONPATH` 指向包含 `scoring/` 的目录。

### 1.2 启用「结合网络」的在线评测（可选）

默认不配置任何环境变量时，引擎走**本地 Vosk 离线兜底**，功能完整、可断网使用，
但发音/语音语调维度是保守近似。

```bash
export SOLOTALK_ASR_ENDPOINT="https://your-asr.example.com/v1/evaluate"
export SOLOTALK_ASR_KEY="your-token"          # 可选
python3 SoloTalk_optimized.py
```

在线端点约定（`POST` multipart/form-data，字段 `audio`）：

```json
{
  "text": "识别出的英文文本",
  "pronunciation": 0.92,      // 音素/词级平均置信度 0~1（用于语音语调、语音维度）
  "duration": 22.5,           // 秒（用于语速）
  "wpm": 128,                 // 可选，直接给语速
  "pause_ratio": 0.12,        // 停顿占比 0~1（用于流利度）
  "grammar": 0.88             // 语法规范度 0~1（用于语言维度）
}
```

**隐私**：只上传作答录音；`text` 之外的韵律字段可选，缺哪个引擎就对哪个维度走保守近似。
`AutoASRProvider` 在超时/断网/HTTP 异常时自动回退本地识别，并在
`score_report.online_used` 里记录本次来源，UI 可提示「在线评分 / 离线近似评分」。

### 1.3 新的返回字段

`evaluate_recordings()` 的返回结构与原实现**完全一致**（`partA` / `partB_three` /
`partB_five` / `partC`），旧 UI 的 `_eval_total_score()` 无需改动；额外附带：

```python
ev["score_report"] = {
    "paper_score": 57.06,       # 卷面 0~60
    "paper_max": 60.0,
    "final_score": 19,          # 折算 0~20（四舍五入）
    "final_max": 20,
    "band": "A",                # A/B/C
    "online_used": True,
    "partA": {"pronunciation": 10.4, "pace_content": 8.0, "total": 18.4, "band": "A", ...},
    "partB": {"questions": [{"language":1.5,"information":0.5,"total":2.0}, ...], ...},
    "partC": {"content":12.0,"language":3.6,"fluency":4.4,"pronunciation":3.0,"total":23.0, ...},
    "config": {"convert": "÷3 四舍五入", "weights": {...}}
}
```

可在结果页增加一个「评分明细」折叠区展示逐维度分数，不改原有逻辑。

## 二、安卓版（Kotlin）

### 2.1 放置文件

```
app/src/main/java/com/solotalk/scoring/
├── GdCelstScoring.kt          评分内核（零依赖）
└── SoloTalkScoringBridge.kt   题库读取 + 在线 ASR 客户端
app/src/main/assets/question_bank/
├── bank_index.json             （18 套索引，含出处元数据）
└── *.solo                      （18 套，从本工程 assets/ 原样拷贝，共约 518 KB）
```

> 题库已扩充为 **18 套带出处试题**（10 套真题公开整理版 / 2 套回忆版 / 1 套模拟 /
> 1 套用户上传原题 / 4 套原创改编），逐套出处见 `05_试题出处清单.md`。
> 每套 `.solo` 同时含**电脑版 CELST 字段**与**手机版听说综合字段**，两种界面都能读；
> 仅 `jm_b8_listen_08.solo` 含 3 段听力 mp3，需用 `SoloTalkScoringBridge` 按需解压。
> 索引 schema 升级为 `solotalk.bank/4`，新增 `category` / `urls` / `fidelity` 等出处字段。

`GdCelstScoring.kt` 只用 Kotlin 标准库；`SoloTalkScoringBridge.kt` 用 Android `Context`、
平台自带 `org.json` 与 `HttpURLConnection`，**不需要 OkHttp / Gson / 任何第三方库**。

### 2.2 调用示例

```kotlin
val items = SoloQuestionBank.index(context)          // 只读索引
val spec  = SoloQuestionBank.readSpec(context, items[0])   // 只流式读 data.json

// 逐槽位拿到 AsrResult（在线优先 / 离线兜底由你的录音模块决定）
val asrA   = try { OnlineAsrClient(endpoint, apiKey).recognize(wavA) }
             catch (e: Exception) { AsrResult(text = localRecognize(wavA), source = "offline") }
// ... 三问 / 五答 / Part C 同理

val report = gradeOnce(spec, asrA, asrThree, asrFive, asrC)
// report.finalScore  = 折算后 0~20
// report.paperScore  = 卷面 0~60
// report.band        = A/B/C
// report.partC.content / language / fluency / pronunciation  = 逐维度分

// 若沿用旧的历史记录/结果页数据结构：
val legacy = report.toLegacyMap()
```

### 2.3 Gradle 瘦身配置

```kotlin
android {
    defaultConfig {
        ndk {
            // 真机主流只需 arm64-v8a；若需兼容老设备再加 armeabi-v7a
            abiFilters += listOf("arm64-v8a")
        }
    }

    // 更推荐：直接发布 App Bundle，由 Google Play / 应用市场按 ABI 下发
    bundle { abi { enableSplit = true } }

    buildTypes {
        release {
            isMinifyEnabled = true          // R8：精简 9 个 dex
            isShrinkResources = true        // 移除未引用资源
            proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"),
                          "proguard-rules.pro")
        }
    }
}

dependencies {
    // ❌ 删除：implementation("com.microsoft.onnxruntime:onnxruntime-android:...")
    // ❌ 删除：implementation("...:vosk-android:...")   （改为按需下载模型）
    // ✅ 评分引擎不需要任何新增依赖
}
```

同时从 `app/src/main/assets/` 删除 `bge-model/`、`vosk-model/`
（详见 `03_内存与体积优化报告.md`）。

### 2.4 在线 ASR 权限

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
```

建议配置 `network_security_config.xml` 限制明文流量，仅允许你的评测域名。

## 三、扩充题库

按 `.solo` 格式（`ZIP` 内 `data.json`）自行添加，或编辑 `tools/build_question_bank.py`
里的 `PACKAGES` 后重新生成：

```bash
python3 tools/build_question_bank.py
```

字段必须遵循 `SoloPackage.to_dict()`：

```jsonc
{
  "meta": {"name","version","created","author","source","disclaimer"},
  "partA": {"video": null, "hidden_text": "模仿朗读原文"},
  "partB": {
    "situation": "情景介绍",
    "listening_text": "听力原文（TTS 用）",
    "listening_audio": null,
    "three_questions": [{"cn_prompt","en_answer","hidden_answer","en_audio":null}, ...3 条],
    "five_answers":    [{"en_question","hidden_answer","q_audio":null}, ...5 条]
  },
  "partC": {
    "summary": "中文梗概", "keywords": "关键词",
    "source_type": "tts", "tts_text": "故事全文",
    "audio": null,
    "key_points": "point one, point two, point three"   // ⚠️ 必须英文逗号分隔
  }
}
```

> `key_points` 用英文逗号分隔是**原程序的硬性要求**（README 第 2 条），
> 写成中文逗号会导致要点无法识别。
>
> 从 QQ 群「共创题目」拿到 `.solo` 后，直接放进 `assets/question_bank/`
> 并在 `bank_index.json` 追加一条索引即可；评分引擎对题目来源无感知。

## 四、常见坑

| 现象 | 原因 / 处理 |
|---|---|
| `ModuleNotFoundError: No module named 'scoring'` | 未保持目录结构。设置 `PYTHONPATH` 指向工程根目录，或把 `scoring/` 放到脚本同级 |
| 离线评分里「语音」维度总是 ≤2 分 | 设计如此：无音素级评测时保守不给 A 档。配置在线端点后可拿满 3 分 |
| `key_points` 全不命中 | 检查是否用了中文逗号；要点应是**关键短语**而非整句 |
| Part A 得分偏低 | 检查 `hidden_text` 是否与视频字幕一致；离线识别（Vosk）准确率会直接影响对齐分 |
| 折算分与预期差 1 分 | 官方是四舍五入；引擎用 `floor(x+0.5)`，不要用 `round()`（银行家舍入） |
| 题库里的大视频不显示 | 按需加载器对单个媒体设 32 MB / 累计 64 MB 上限。超大媒体请压缩后重新打包，或改为流式播放 |
